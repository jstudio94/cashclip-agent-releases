# CashClip Agent 다운로드

네이버 블로그 자동 발행 데스크톱 앱입니다.

## 설치
1. 아래 최신 버전에서 `CashClipAgent-Setup-x.y.z.exe` 를 받습니다 → [**Releases**](../../releases/latest)
2. 실행 후 설치합니다.
   - Windows SmartScreen "알 수 없는 게시자" 경고가 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명 인증서 적용 전까지 나타납니다.)
3. 처음 실행 시 캐시클립 대시보드에서 발급받은 **에이전트 키(X-Extension-Key)** 를 입력합니다.

## 필요한 것
- Windows 10/11 (64비트)
- Chrome 브라우저
- 캐시클립 **에이전트 이용권** (관리자에게 문의)
- 본인 Gemini API 키 (글·이미지 생성용)

## 자동 업데이트
새 버전이 나오면 앱이 시작할 때 자동으로 확인하고, 동의하면 받아서 설치합니다.
